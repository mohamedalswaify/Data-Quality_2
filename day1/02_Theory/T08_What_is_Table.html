08 — ما هو الجدول في SQL؟

تخيل Excel

الجدول في SQL يشبه شيت Excel:

  • الصف = سجل (عميل واحد)
  • العمود = حقل (الاسم، الجوال، المدينة...)
جداول سنستخدمها اليوم
  • customers = العملاء
  • orders = الطلبات
قاعدة التدريب اسمها: Abad_DataQuality_Lab
خلاصة

SQL تسأل الجدول أسئلة، والجدول يرد بصفوف.
