04 — معامل SQL السهلة + الحل تحت كل Lab

أول مرة فقط نفّذ الملفين: 01_Create_Database.sql ثم 02_Seed_Dirty_Data.sql من SSMS أو Azure Data Studio (زر Execute).
Lab 1 — شوف العملاء
اعرض 10 عملاء.
USE Abad_DataQuality_Lab; SELECT TOP 10 customer_id, full_name, phone, email, city FROM dbo.customers;
فقط مشاهدة. لاحظ بنفسك أي خانات فاضية أو غريبة.
Lab 2 — عدّ الجداول بسرعة
كم صف في customers و orders؟
SELECT COUNT(*) AS customers_count FROM dbo.customers; SELECT COUNT(*) AS orders_count FROM dbo.orders;
المتوقع تقريبًا: customers=23 ، orders=15
هذا استكشاف أولي: نعرف حجم البيانات.
Lab 3 — القيم الناقصة في الجوال
أظهر ثم عُدّ الجوالات الناقصة.
-- العرض SELECT customer_id, full_name, phone FROM dbo.customers WHERE phone IS NULL OR LTRIM(RTRIM(phone)) = ''; -- العدد SELECT COUNT(*) AS missing_phone FROM dbo.customers WHERE phone IS NULL OR LTRIM(RTRIM(phone)) = '';
أول قياس جودة حقيقي وبسيط: كم ناقص؟
Lab 4 — اكتمال الإيميل بنسبة
طلع نسبة اكتمال الإيميل.
SELECT COUNT(*) AS total_rows, SUM(CASE WHEN email IS NOT NULL AND LTRIM(RTRIM(email)) <> '' THEN 1 ELSE 0 END) AS has_email, CAST(100.0 * SUM(CASE WHEN email IS NOT NULL AND LTRIM(RTRIM(email)) <> '' THEN 1 ELSE 0 END) / COUNT(*) AS DECIMAL(5,2)) AS email_completeness_pct FROM dbo.customers;
ركّز على العمود الأخير فقط.
نفس فكرة تاسك 5. النسبة تسهل الكلام مع الإدارة.
Lab 5 — الإيميلات المكررة
اطبع الإيميلات اللي اتكررت.
SELECT email, COUNT(*) AS cnt FROM dbo.customers WHERE email IS NOT NULL AND LTRIM(RTRIM(email)) <> '' GROUP BY email HAVING COUNT(*) > 1 ORDER BY cnt DESC;
لو cnt = 2 معناها الإيميل ظهر مرتين. هذه بداية اكتشاف عملاء مكررين.
Lab 6 — طلبات بدون عميل (اختياري سهل)
هل في طلبات لعميل مش موجود؟
SELECT order_id, customer_id, status FROM dbo.orders WHERE customer_id IS NULL OR customer_id NOT IN (SELECT customer_id FROM dbo.customers WHERE customer_id IS NOT NULL);
إذا ظهر صف هنا، العلاقة بين الطلبات والعملاء مكسورة (Integrity).
